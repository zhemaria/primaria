Odd and even

The counters are lined up in pairs. If every counter has a partner, the number is even. If one is left alone, the number is odd. An even number can always be split into two equal groups.

An array is rows of counters, all the same length. Instead of counting every counter, count one row and then add that number once for each row. Write one box for each row, then the total.
